# 개인 솔로 레이드 기록

이 파일은 사용자가 제공한 실전 사실만 보관한다. 과거 미기록 사항을 현재 메타나 추정으로 보완하지 않는다.

## 사용자 공통 플레이 성향

- 솔로 레이드 기간 전제: 한 시즌은 평균 7일간 진행
- 초반 2일: 도전 난이도가 열리지 않아 사실상 기본 보상을 획득하는 구간
- 실질적인 순위 경쟁 기간: 도전 난이도가 개방되는 3일 차부터 시즌 종료까지
- 솔로 레이드 조작 방식: 모든 덱을 전부 수동 조작
- 향후 덱 구성 선호: 가능하면 각 덱에 버스트 게이지 수급을 담당할 캐릭터를 최소 1명 배치
- 이유: 버스트 게이지를 빠르게 채워 풀 버스트를 한 번이라도 더 사용하면 총 피해량 상승으로 이어질 가능성이 높음
- 대표 수급 방식: RL 캐릭터의 `톡톡이` — 풀 차지하지 않고 최소 차지 공격을 빠르게 연사해 버스트 게이지를 당김
- 현재 큐브 운용 상태(2026-08-17 사용자 진술): 렐릭 큐브 12레벨
- 현재 솔로 레이드 큐브 운용: 한 덱의 5명 모두 렐릭 큐브 장착
- 큐브 운용 제약: 큐브 레벨업에 장기간이 필요해 현재 계정에서는 여러 종류의 큐브를 충분히 육성해 나눠 쓰기 현실적으로 어려움
- 향후 덱 추천 원칙: 현재 큐브 육성 상태가 바뀌기 전까지는 5명 모두 렐릭 큐브 사용을 기본값으로 두고, 다른 큐브를 전제로 한 추천은 추가 육성 비용을 명시
- 캐릭터 레벨 처리: 솔로 레이드는 모든 사용자가 400레벨로 고정되는 콘텐츠이므로 덱 분석과 과거 기록에서 캐릭터 레벨은 비교 변수에서 제외
- 향후 기록 질문 원칙: 각 덱의 `다시 한다면 조합이나 운용을 바꿀지`는 별도로 묻지 않음

### 보스 프로필 및 기믹

#### 설명글에서 가져온 특성

- 1페이즈와 2페이즈 모두 상시 코어 판정이 존재하지만 명중률이 낮음
- 패턴으로 주기적으로 출현하는 파츠가 있음
- 색깔 맞추기에서 파괴하는 공도 파츠 판정으로 취급
- 그로기 횟수는 총 6회로 비교적 넉넉한 편

#### 색깔 맞추기 패턴

- 3분 전투의 남은 시간 기준 등장 시점: 2분 12초, 1분 36초, 1분 02초, 22초
- 노란색 공 3개와 보라색 공 3개, 총 6개가 등장
- 중앙에 표시된 색과 같은 공 3개를 파괴하면 패턴 파훼
- 등장하는 공은 모두 파츠 판정

#### 총기 소환 패턴

- 보스가 타격하는 총기를 소환
- 후반에는 총기를 4개까지 소환하기도 함
- 소환 총기는 모두 파츠 판정
- 파츠 파괴 대미지 효과를 가진 니케가 높은 점수를 얻기 좋은 보스 구조

#### 저지원 패턴

- 약 1분 58초: 속성 저지가 아닌 일반 저지원. 빠르게 제거해야 함
- 약 49초: 속성 저지원. 풍압 속성 공격으로 파괴해야 함

- 실제 버스트 순서:

  2. 아니스: 스타(B1) → 마스트: 로망틱 메이드(B2) → 홍련: 흑영(B3)
  3. 위 두 사이클을 같은 순서로 반복
- 선버 주의사항: 애니힐리오에서는 앵커·리버렐리오 사이클을 먼저 사용했지만, 이 선버 순서가 다른 모든 보스에서도 더 강하다는 의미는 아님. 보스 기믹과 딜 타이밍에 따라 마스트·홍련: 흑영 선버가 더 적합할 수 있으므로 보스별로 다시 판단
- B2 교대 이유: 마스트의 버스트 쿨타임이 40초이므로 다른 B2가 한 명 더 필요하며, 앵커: 이노센트 메이드 또는 크라운을 주로 함께 사용함. 이 시즌 1덱에서는 앵커를 사용
- 주 조작 캐릭터: 앵커: 이노센트 메이드
- 주 조작 이유: RL 캐릭터인 앵커로 `톡톡이`를 사용해 버스트 게이지를 빠르게 확보하기 위해서
- RL 구성 주의: 1덱에는 앵커: 이노센트 메이드, 아니스: 스타, 홍련: 흑영까지 RL 캐릭터가 3명 있지만 모두 톡톡이가 가능한 것은 아님
- 톡톡이 가능 여부: 앵커: 이노센트 메이드는 가능하며, 아니스: 스타와 홍련: 흑영은 불가능
- 따라서 RL 3명 중 실제 버스트 게이지 수급 및 주 수동 조작 담당은 앵커: 이노센트 메이드로 선정
- 톡톡이 방식: 공격을 풀 차지하지 않고 최소 차지로 연사해 버스트 게이지를 당김
- 운용 목적: 버스트 회전 속도를 높여 전투 중 풀 버스트 사용 횟수를 늘리고 총 피해량 상승을 노림
- 버스트 사용 원칙: 색깔 맞추기나 총기 소환 패턴을 위해 보존하지 않고 준비되는 즉시 사용
- 즉시 사용 이유: 버스트를 한 번이라도 더 사용해 총 피해량을 높이기 위해서
- 당시 큐브 상태: 1덱 5명 모두 11레벨 렐릭 큐브 장착

##### 마스트·앵커 세트 운용 원리

- 마스트의 `취기`는 최대 3중첩
- 버스트 1단계 진입 때 마스트가 취기를 쌓음. 마스트 단독 메커니즘상 최대 3중첩 상태에서 풀 버스트가 끝나면 취기가 해제되고 마스트가 1초간 기절
- 앵커의 1스킬은 풀 버스트 시작 횟수에 따라 효과가 누적되며, 2회째에 분배 대미지 29.01% 증가가 적용됨
- 앵커의 1스킬은 풀 버스트 3회째에 `중첩 가능 해로운 효과 중첩량 1개 감소`를 적용하며, 이 효과가 마스트의 취기 중첩에도 적용됨
- 따라서 마스트·앵커 조합에서는 취기가 최대 3중첩 기절 조건에 도달하지 않아, 마스트가 버스트를 3번 사용해도 기절하지 않음
- 홍련: 흑영의 주요 대미지가 분배 대미지이므로 앵커의 분배 대미지 증가를 받게 하기 위해 마스트·앵커 조합을 사용
- 마스트와 홍련: 흑영을 같은 버스트 사이클로 묶은 이유: 홍련: 흑영이 마스트의 크리티컬 확률 증가와 분배 대미지 증가를 가장 효율적으로 받을 수 있는 캐릭터이기 때문
- 앵커의 2스킬은 풀 버스트 종료 횟수에 따라 효과가 적용되며, 3회째에 재장전 속도 34.63% 증가가 적용됨
- 마스트의 재장전 속도 증가, 앵커의 재장전 속도 증가, 렐릭 큐브의 재장전 관련 효과를 합치면 사용자의 설명 기준 합산 100%를 초과
- 이 상태에서는 엄폐를 약 0.1초만 해도 재장전이 완료되어 사실상 `무한 장탄`처럼 운용 가능
