# 소장품·애장품 상세 현황

직접 확인한 캐릭터별 스킬명과 레벨은 [skill-details.md](skill-details.md)를 함께 확인한다.
캐릭터별 속성은 [element-classification.md](element-classification.md)를 함께 확인한다.

출처: ShiftyPad 캐릭터 상세의 소장품 화면 직접 확인.

- `소장품`과 캐릭터 전용 `애장품`을 구분하여 기록한다.
- 화면에 표시되지 않은 단계나 효과는 추정하지 않는다.
- 캐릭터별 확인 순서는 `장비 → 스킬 → 소장품`으로 고정한다.
- 장비 화면을 먼저 기록한 뒤 사용자가 스킬 화면과 소장품 화면을 차례로 열면 각각 이어서 기록한다.
