# 캐릭터 속성 분류

캐릭터별 총기 종류는 [weapon-classification.md](weapon-classification.md)를 함께 확인한다.

출처: ShiftyPad 니케 목록에서 속성 필터를 적용한 화면 직접 확인.

- 사용자가 해당 속성만 표시된 화면임을 확인한 목록만 기록한다.
- 같은 캐릭터의 다른 버전은 별도 캐릭터로 구분한다.
